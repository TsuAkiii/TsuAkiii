## What I've been building

### [OpsDesk](https://opsdesk.jiku.fr/) - IT helpdesk

A helpdesk app for multiple organizations. People can submit tickets, technicians can work through them, and admins can manage their teams. It includes private attachments, activity history, dashboards and access controls between organizations.

**Stack:** Angular 22, ASP.NET Core 10, PostgreSQL, Docker.

[Try the demo](https://opsdesk.jiku.fr/)

### [StockFlow](https://stockflow.jiku.fr/) - Inventory management

A tool for keeping track of products, warehouses, suppliers and purchase orders. It handles stock reservations and transfers, including cases where two people try to reserve the last item at the same time.

**Stack:** Angular 22, Java 21, Spring Boot 4.1, PostgreSQL, Keycloak.

[Try the demo](https://stockflow.jiku.fr/)

### [JIKU](https://jiku.fr/) - Video to social content

My SaaS project for turning videos into content for social platforms. It uses background workers, FFmpeg, object storage and AI-assisted generation.

[Visit JIKU](https://jiku.fr/)
